## User stories

1. User lands on sign-up page so that they can get into the app. ## must
2. If user has no account, they sign-up so that they create an account. ## must
3. If user has an account, they log-in so that they get access to the app. ## must
4. User picks between 2 options - create new workout / choose existing workout so that they can start their workout. ## must
5. User picks an exercise from the list of exercises so that they can choose an exercise. ## must
6. User can search for the exercise in the search bar if they cannot find it in the list so that they find the exercise easier. ## later
6. User can track reps, weight, and sets for that exercise so that they can keep track of that exercise. ## must
7. User saves the exercise so that they can look at it in progress after. ## must
8. User pick another exercise so that they can continue workout. ## must
9. User picks finish workout so that they can end the workout. ## must
10. User can view history so that they can see how many times they've been in the gym. ## later
11. User can select progress so that they can see a progress on the exercises. ## later
12. User can select an exercise so that they can see a progress chart on that specific exercise. ## later
13. User can use TDEE calculator to calculate their TDEE. ## later
14. User can track their weight in the profile. ## later
15. User can log-in with FACE ID. ## later
16. User can have whole week workouts already organized. ## later
