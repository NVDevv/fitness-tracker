## User stories

1. User lands on sign-up page. They can log-in or sign-up if they do not already have an account.
2. User can select existing, or create full new workout.
3. User can record an exercise, how many kgs they've done, reps and sets into selected workout.
4. User can see their workout history per day.
5. User can see their progress chart per exercise amounted in KGs.

## Must

1. User must have an option to create and account.
2. User must be able to create or choose an existing workout.
3. User must be able to track their weight in exercises.
4. User must be able to see their progress chart per exercise.
5. User must be able to check their discipline of coming to the gym by chart or calendar.

## Later
